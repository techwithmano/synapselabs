---
name: Storefront responsive layout
description: The user's repeated requirement for clean alignment and no unintended overlap across device sizes.
---

For the storefront, keep product imagery clear of unrelated callouts and reserve space for every content region. Stack competing content into separate rows when the viewport is narrow.

**Why:** The user repeatedly flagged overlap and explicitly requires cross-device alignment.

**How to apply:** Inspect the full page at phone, tablet, and desktop widths; check horizontal overflow and verify hero, header, and product-card geometry.
