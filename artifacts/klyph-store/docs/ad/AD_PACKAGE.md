## 4. Complete Voiceover Script & Audio Production Guidelines

### Voiceover Casting
- **Voice Profile**: Calm, articulate, warm mid-frequency tone. Unhurried cadence (~2.5 words per second). British or Neutral Mid-Atlantic accent. Feels like an architect or industrial designer, not a salesperson.
- **Tone**: Quiet, Precise, Confident.

### Script Breakdown
```
[0:00 - 0:02]  "Silence isn’t empty."
[0:02 - 0:06]  "It’s calibrated."
[0:06 - 0:10]  "Continuous neural telemetry, with zero screen noise."
[0:10 - 0:13]  "Synapse Labs. Intelligence, in form."
[0:13 - 0:15]  "Experience the collection."
```

### Sonic Branding & Music Design
- **Track Style**: Ambient neo-classical electronics (reference: Brian Eno meets Max Richter and Nils Frahm).
- **Instruments**:
  - Warm analog Rhodes or sub-sine foundation at 40Hz.
  - Granular acoustic bow friction that modulates as the ceramic ring turns.
  - Single crisp acoustic glass chime at the moment of biometric synchronization (0:08).
  - No loud percussion, no aggressive risers, no hyper-pop drops.
- **Mastering**: LUFS -14dB integrated, pristine dynamic range, spatial binaural audio rendering.

```

|  |                    |  |
|  +--------------------+  |
|                          |
|  Bottom Safe Margin (UI) |  <- TikTok / Reels caption & UI area
+--------------------------+
```

- **Top Safe Margin**: 150px (Reels / TikTok header overlay)
- **Bottom Safe Margin**: 280px (Reels audio name, user handle, and comment buttons)
- **Center 1:1 Box**: Coordinates `(0, 420)` to `(1080, 1500)`. All product action, on-screen text, and logos are strictly framed within this 1080x1080 window for dual-format deployment.
