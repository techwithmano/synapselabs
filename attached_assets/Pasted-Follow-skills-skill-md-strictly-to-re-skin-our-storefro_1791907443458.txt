### 3. Authentication (Steps 5, 6, 7 per SKILL.md):
- Password Security: Use bcryptjs to hash passwords with salt rounds of 10. Passwords must be at least 8 characters. Never store or return raw passwords.
- JWT Session: Sign JWT using `process.env.JWT_SECRET` and set it inside an `httpOnly`, Secure, SameSite cookie named `token`.
- Routes:
  - `POST /api/auth/signup`: Validates input, hashes password, saves user to DB, and logs them in via httpOnly cookie.
  - `POST /api/auth/login`: Validates credentials, verifies hash with bcrypt, sets httpOnly cookie, returns user data without passwordHash.
  - `POST /api/auth/logout`: Clears the auth cookie.
  - `GET /api/auth/me`: Reads httpOnly cookie, verifies token, returns current user profile { id, name, email }.
- UI:
  - Clean auth modal or pages (/login and /signup) matching the Synapse white/cobalt aesthetic.
  - Navbar: If logged in, display the user's name, a [My Orders] link, and a [Log Out] button. If logged out, display [Sign In].
